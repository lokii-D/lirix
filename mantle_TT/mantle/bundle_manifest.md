# Bundle Manifest

This manifest enumerates the canonical judge-facing files that must be present in the final Mantle packet.

## Mandatory judge packet files

- `README.md`
- `submission_one_pager.md`
- `architecture.md`
- `video_script.md`
- `delivery_checklist.md`
- `bundle_manifest.md`
- `final_bundle_index.md`
- `test_mantle_config.py`

## Integrity expectation

If any file above is missing, the packet is incomplete for formal review.
