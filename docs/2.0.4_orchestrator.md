# Lirix 2.0.4 Orchestrator — Linear DAG (Judge Brief)

**English (30-second read):**
Lirix 2.0.4 runs a **linear DAG**: `pre_validate_hook` → **L1–L3** → `pre_sim_hook` → **L4** (RPC quorum + spread fail-closed) → **L5** (eth_call + state_override) → policy audit → `post_sim_hook` → `post_validate_hook`.
Outputs include a **Failure Protocol** dict contract, **SHA-256** replay digest, and `registry_closure_digest`.
`HookPatch` may mutate in-place but **does not re-run L1–L3**.
