## CI Gate Responsibility Matrix

This document is the single source of truth for the **purpose**, **inputs**, **outputs**, and
**ownership** of each CI gate used by this repository.

### Principles

- **Minimal required set**: `Fast Required` must remain small and deterministic.
- **Clear failure attribution**: each gate must emit actionable failure messages.
- **Contracted inputs**: each gate must declare where its inputs come from (repo file, workflow,
  generated artifact, or live GitHub API).
- **Test coverage**: every custom gate in `tools/` must have at least one `tests/test_tools/*`
  test that proves the CLI can run in a clean checkout.

### Gate Inventory (current lanes)

- **Fast Required**: `.github/workflows/ci.yml` → job `fast_required`
- **PR Compatibility Smoke**: `.github/workflows/ci.yml` → job `pr_compat_smoke` (PR-only)
- **Coverage Required (Single Authority)**: `.github/workflows/ci.yml` → job `coverage_required` (non-PR)
- **Non-required / Governance lane**: see `.github/workflows/*.yml` (and `docs/branch_protection_required_checks.md`)
